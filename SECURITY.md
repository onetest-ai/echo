# Security

Echo handles sensitive material: call audio while recording, transcripts, meeting chat and a
Microsoft 365 sign-in. If you find a vulnerability, please **don't open a public issue**. Report
it privately through GitHub: **Security → Report a vulnerability** on this repository.

Include what you found, how to reproduce it, and which version you used. You'll get a reply
within a week.

What counts as in scope: anything that lets another process, website or user read call data or
tokens, record without the user's opt-in, run code through the update, the `echo://` window or
the CLI, or send data off the device.
