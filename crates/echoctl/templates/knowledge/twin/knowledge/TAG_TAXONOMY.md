# Tag Taxonomy

> The allowed tags of this vault. Obsidian-compatible. **Only tags listed here may be used.**
> Last updated: {{vault.date}}

---

## Rules

1. **Only tags from the lists below are allowed.** Do not invent new tags.
2. **Every page carries one type tag, first** in its `tags:` array.
3. **Add domain and entity tags** when the page is really about them.
4. **To add a tag**: stop, name the gap, and ask the owner. An approved tag is added here and to the log below.
5. **No person names, tool names or one-off specifics** as tags — those belong in the text.

## Approved Tags

### Type — what kind of page is this?

| Tag | Use when |
|-----|----------|
| `meeting` | A meeting, call, sync, standup, demo, workshop, interview |
| `concept` | A framework, proposal, model, idea not yet carried out |
| `reference` | A guide, profile, style or how-to you come back to |
| `analysis` | Research, comparison, evaluation, a data-backed deep dive |
| `client` | A client or organisation: engagement, account, opportunity |
| `media` | An article, talk, interview, post or publication |
| `task` | An open task, commitment or follow-up list |
